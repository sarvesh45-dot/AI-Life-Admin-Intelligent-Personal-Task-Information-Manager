# 🤖 AI Life Admin

> Don't manage your information. Let AI manage the work.

AI Life Admin is a GenAI-powered personal productivity assistant that transforms messy information into organized tasks, deadlines, priorities, categories, and actionable insights.

Instead of manually creating tasks, users can simply tell the AI what they need to do. Gemini understands the information and converts it into structured actions.

## ✨ Features

- 🤖 AI-powered task extraction
- 📝 Convert natural language into tasks
- 📅 Automatic deadline detection
- 🚦 AI priority classification
- 🗂️ Smart task categorization
- 📸 Screenshot and image understanding
- 🔍 Natural-language task search
- 📊 AI productivity insights
- ✅ Task completion tracking
- ✏️ Edit and delete tasks
- 💾 LocalStorage data storage
- 🌑 Premium dark 3D interface
- 📱 Fully responsive design

## 🧠 How It Works

User Input
    ↓
Text / Screenshot / Information
    ↓
Gemini AI
    ↓
Information Understanding
    ↓
Task + Deadline + Category + Priority
    ↓
AI Life Admin Dashboard
    ↓
Actionable Tasks

## 💡 Example

User Input:

"I need to submit my DBMS project by Friday, pay my electricity bill before September 10, and buy a notebook."

📚 DBMS Project
Category: College
Deadline: Friday
Priority: High

💰 Electricity Bill
Category: Finance
Deadline: September 10
Priority: Medium

🛒 Buy Notebook
Category: Shopping
Priority: Low

## 📸 Screenshot Understanding

AI Life Admin can analyze screenshots or images containing useful information.

Example:

"Submit project report by Friday."

Gemini extracts:

Task: Submit Project Report
Deadline: Friday
Category: College
Priority: High

The user can review the result before adding it to the task list.

## 🤖 AI Search

Users can ask questions using natural language.

Examples:

"What do I need to finish this week?"

"Show my urgent college tasks."

"What deadlines do I have this month?"

"What tasks are overdue?"

The AI analyzes the user's tasks and provides relevant answers.

## 📊 AI Insights

The application can analyze tasks and provide productivity insights such as:

- Number of upcoming deadlines
- Overdue tasks
- Most common task category
- High-priority workload
- Productivity suggestions

Example:

"You have 4 deadlines this week. Most of your pending tasks are related to college."

## 🚀 Getting Started

### 1. Clone the Repository

git clone https://github.com/YOUR-USERNAME/ai-life-admin.git

### 2. Open the Project

cd ai-life-admin

### 3. Install Dependencies

npm install

### 4. Configure Gemini API

Configure your Gemini API key using the environment or secrets configuration required by the project.

IMPORTANT: Never expose or commit your API key to GitHub.

### 5. Start the Development Server

npm run dev

Open the local URL displayed in the terminal.
